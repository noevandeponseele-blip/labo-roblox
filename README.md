# Labo des jeux Roblox

Site qui analyse les 1000 jeux Roblox les plus joués (genres, mots-clés, jeux qui percent, recettes) et génère des idées de jeux.

- Site : https://noevandeponseele-blip.github.io/labo-roblox/
- Données : classements officiels de Roblox, relevés dans ~100 pays et 6 types d'appareils, classés par joueurs connectés.
- Mise à jour : toutes les heures via GitHub Actions (`.github/workflows/update.yml`). Pour forcer une mise à jour : onglet **Actions** → « Mise à jour du top 1000 » → **Run workflow**.
